# Secure Variance-Based Adaptive Steganography Framework Using Integer Wavelet Transform

A cryptographically secure adaptive image steganography framework based on Integer Wavelet Transform (IWT), Palette scrambling, and variance-driven adaptive embedding.

Presented at:

**6th International Conference on Computer Vision and Robotics (CVR 2026)**  
National Institute of Technology Goa (NIT Goa)

---

# Overview

This project proposes a secure and adaptive image steganography framework using:

- Integer Wavelet Transform (IWT)
- Discrete Wavelet Transform (DWT)
- Key-Based Position Scrambling (Palette)
- Variance-Driven Adaptive Bit Allocation (AdaptPalette)
- Statistical Histogram Security Analysis

The framework is designed to optimize:

- Visual imperceptibility
- Payload capacity
- Statistical security
- Extraction fidelity
- Computational efficiency

---

# Key Features

- Lossless Integer Wavelet Transform implementation
- Cryptographic coordinate scrambling using MD5-seeded PRNG
- Adaptive embedding using sub-band variance analysis
- Robustness testing against:
  - JPEG compression
  - Gaussian noise
  - Median filtering
  - Gaussian blur
- Histogram-based steganalysis evaluation
- Automatic LaTeX table generation
- Research-grade benchmarking framework
